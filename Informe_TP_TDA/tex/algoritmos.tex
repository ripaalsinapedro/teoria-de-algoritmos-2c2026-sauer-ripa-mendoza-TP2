\section{Algoritmo para elegir las monedas}

En este trabajo de ejemplo realizaremos el análisis teórico y empírico de diferentes algoritmos que sirven para resolver el mismo problema: obtener el orden en que se deben elegir las monedas para maximizar la ganancia obtenida de un arreglo de $n$ monedas. 

\subsection{Algoritmo para encontrar el optimo}

El algoritmo presente construyer una matriz de $N \times N$, siendo $n$ la cantidad de monedas totales. Cada posición $(i,j)$ de la matriz almacena la solución óptima para el subproblema de dimesiones correspondientes.
En primer lugar, se completan las diagonales correspondientes a los casos base, la diagonal principal $(i = j)$  y la superiro $(i = j + 1)$ con los siguientes valores, correspondientes a los dos casos base:

\begin{itemize}
    \item tener una sola mondea, donde el optimo es la moneda en si.
    \item tener dos monedas, donde el optimo es la mas grande entre la dos.
\end{itemize}
Luego recorremos la parte superior de la matriz (ya que los punteros $i$, $j$ que 
apuntan al principio y final del array de monedas respectivamente, nunca se
intercambian, lo que es igual y se cumple que $i <= j$), llenando cada posición de la matriz con la solucion del problema de tamaño correspondiente.
Es asi que una vez completamos toda la matriz, encontramos la solucion óptima para nuestro problema original en las coordenada $i = 0$ y $j = n$.

Aqui el código usado para generar la matriz con los valores óptimos para todos los problemas de dimensiones $i$, $j$.

\begin{lstlisting}[language=Python]
def elegir(monedas):
    opt = [[0] * len(monedas) for i in range(len(monedas))]
    
    # Casos base con una moneda
    for i in range(0, len(monedas)):
        opt[i][i] = monedas[i]
        
    # Casos base con 2 monedas
    for i in range(0, len(monedas) - 1):
        j = i + 1
        opt[i][j] = max(monedas[i], monedas[j])
    
    for i in range(len(opt) - 1, -1, -1):
        for j in range(i + 2, len(opt)):
            # Sophia toma la primera
            # Achico mi rango segun lo que eliga Mateo
            opt_i = opt[i + 2][j] if monedas[i + 1] > monedas[j] else opt[i + 1][j - 1]
            
            # Sophia toma la ultima
            # Achico mi rango segun lo que eliga Mateo
            opt_j = opt[i + 1][j - 1] if monedas[i] > monedas[j - 1] else opt[i][j - 2]
            
            opt[i][j] = max(monedas[i] + opt_i, monedas[j] + opt_j)
            
    maxima_ganancia = opt[0][len(opt) - 1]
    sol = solucion(opt, monedas, [], 0, len(opt) - 1)
    return maxima_ganancia, sol
\end{lstlisting}

La matriz de solución óptima se construye de la siguiente manera. Para cada subproblema definido por los indices $i$ y $j$, cuyo objetivo es maximizar la ganancia, se analizan dos posibles elecciones, tomar la primera moneda ubicada en $i$ o tomar la que se encuentra ubicada en la ultima posocion $j$. A partir de estas dos alternativas se pueden analizar las siguientes opciones:

\begin{enumerate}
    \item Sophia toma la primera moneda, la moneda $i$ y Mateo elige la mayor entre las monedas $i + 1$ y $j$.

    \begin{enumerate}
        \item Si mateo eligie la moneda $i + 1$ el rango $(i, j)$ se achica a $(i + 2, j)$, por lo que nuestra solución sera el valor de la moneda $i$ más la solución del rango $(i + 2, j)$.

        $$opt(i, j) = moneda_i + opt(i + 2, j)$$

        \item Si mateo eligie la moneda j el rango $(i, j)$ se achica a $(i + 1, j - 1)$, por lo que nuestra solución sera el valor de la moneda $i$ más la solución del rango $(i + 1, j - j)$.

        $$opt(i, j) = moneda_i + opt(i + 1, j - 1)$$

    \end{enumerate}

    \item Sophia toma ahora la última moneda, la moneda $j$ y Mateo elige la mayor entre las monedas $i$ y $j - 1$.

    \begin{enumerate}
        \item Si mateo eligio la moneda $i$ el rango $(i, j)$ se achica a $(i + 1, j - 1)$, por lo que nuestra solución sera el valor de la moneda j más la solución del rango $(i + 1, j - 1)$.

        $$opt(i, j) = moneda_j + opt(i + 1, j - 1)$$

        \item Si mateo eligio la moneda $j$ el rango $(i, j)$ se achica a $(i, j - 2)$, por lo que nuestra solución sera el valor de la moneda j más la solución del rango $(i, j - 2)$.

        $$opt(i, j) = moneda_i + opt(i, j - 2)$$
    \end{enumerate}
\end{enumerate}

Luego de plantear estas cuatro situaciones, podemos observar que, independientemente de la elección de Sophia, Mateo siempre elegirá la moneda de mayor valor entre las dos disponibles en los extremos del intervalo. Por lo tanto, en cada caso, basta con comparar ambas monedas para determinar cuál elegirá Mateo.


Esta comparación permite determinar los límites del subproblema restante y, a partir de ellos, obtener las soluciones parciales correspondientes a cada alternativa. Finalmente, se comparan ambas soluciones y se selecciona aquella que maximiza la ganancia de Sophia.

Siendo $opt_i$ la solución del subproblema resultante de que Sophia elija la moneda ubicada en la posición $i$, y $opt_j$ la solución del subproblema resultante de que Sophia elija la moneda ubicada en la posición $j$ , el valor óptimo para el intervalo $(i,j)$ se obtiene de la siguiente manera:

\[
\text{opt}(i, j) = \max \left( \text{moneda}_i + \text{opt}_i, \; \text{moneda}_j + \text{opt}_j \right)
\]

donde:
\[
\text{moneda}_i + \text{opt}_i = 
\begin{cases} 
\text{monedas}[i] + \text{opt}(i + 2, j) & \text{si } \text{monedas}[i + 1] > \text{monedas}[j] \\[1ex]
\text{monedas}[i] + \text{opt}(i + 1, j - 1) & \text{sino}
\end{cases}
\]

\[
\text{moneda}_j + \text{opt}_j = 
\begin{cases} 
\text{monedas}[j] + \text{opt}(i + 1, j - 1) & \text{si } \text{monedas}[i] > \text{monedas}[j - 1] \\[1ex]
\text{monedas}[j] + \text{opt}(i, j - 2) & \text{sino}
\end{cases}
\]

\subsection{Casos de empates}

En el $TP1$, partimos de la base que el conjunto $M$, posee todas monedas diferentes, sin embargo, en este caso aceptaramos monedas de valores similares, por lo que nos resulta interesante ver que pasa si tenemos mondeas del mismo valor.
En el turno de Sophia, de haber monedas de igual valor en ambos extremos tal que.

\[
\text{moneda}_i = \text{moneda}_j
\]

El desempate termina siendo el maximo entre las soluciones parciales del problema. Vemos que el óptimo para el problema $(i, j)$ termina siendo.

\[
\text{opt}(i, j) = 
\max \left( \text{moneda}_i + \text{opt}_i, \; \text{moneda}_j + \text{opt}_j \right) = 
\max \left( \text{moneda}_i + \text{opt}_i, \; \text{moneda}_i + \text{opt}_j \right)
\]

\[
\text{opt}(i, j) = \max \left(\text{opt}_i, \;\text{opt}_j \right)
\]

En caso de que tengamos, de nuevo, mondeas de igual valor en ambos extremos, pero en este caso, siendo el turno de Mateo, ahora lo que debemos analizar es como se reduce la dimensión de nuestro problema. Anteriormente habiamos visto que.

\[
\text{opt}_i = 
\begin{cases} 
\text{monedas}[i] + \text{opt}(i + 2, j) & \text{si } \text{monedas}[i + 1] > \text{monedas}[j] \\[1ex]
\text{monedas}[i] + \text{opt}(i + 1, j - 1) & \text{sino}
\end{cases}
\]

\[
\text{opt}_j = 
\begin{cases} 
\text{monedas}[j] + \text{opt}(i + 1, j - 1) & \text{si } \text{monedas}[i] > \text{monedas}[j - 1] \\[1ex]
\text{monedas}[j] + \text{opt}(i, j - 2) & \text{sino}
\end{cases}
\]

Si vemos, en ambos casos usamos un mayor esticto para definir los optimos $\text{opt}_i$, $\text{opt}_j$. Por lo que si planteamos lo siguente.

\[
\text{monedas}[i + 1] = \text{monedas}[j]
\]

\[
\text{monedas}[i] = \text{monedas}[j - 1]
\]

Los optimos resultan.

\[
\text{opt}_i = \text{monedas}[i] + \text{opt}(i + 1, j - 1)
\]

\[
\text{opt}_j = \text{monedas}[j] + \text{opt}(i, j - 2)
\]


\subsection{Algoritmo para obtener la reconstruccion de la solución}

Partiendo de la matriz óptima, desarrollamos un algoritmo que brinde la secuencia de monedas que se deberian elegir para obtener la ganancia maxima, mediante llamadas recursivas.

\begin{enumerate}
    \item Casos base.
    \begin{itemize}
        \item $i < j$ El rango de monedas es invalido, finalizo la recursión y devuelvo la solución.
        \item $i = j + 1$ Quedan solo dos monedas, por lo que Sophia elige la mayor
    \end{itemize}

    \item Evaluacion de alternativas (esta es la parte donde analizamos que subproblema conforma la solución del problema actual y se simula la elección de monedas).
    \begin{itemize}
        \item Se calcula $opt_i$ y $opt_j$ de la misma manera que en el algoritmo anterior, siendo los optimos si se elije la moneda $i$ o la moneda $j$, y en concecuencia que moneda elijiria Mateo (la mayor), y como estas decisiones afectan las dimensiones de nuestro problema.
        \item Analizamos que óptimo nos da la mayor ganancia si le sumamos la mondea correspondiente (porque es lo que el algoritmo hubiera hecho), y en base al mayor agremos el indice $i$ o el $j$ a la solución, respectivametne.
        \item Por ultimo vemos que moneda elije Mateo, cual es la mayor, y llamamos a la función recursivamente con el nuevo rango $i$, $j$ conseguido luego de analizar las decisones que tomarian ambos bandos.
    \end{itemize}
\end{enumerate}

\begin{lstlisting}[language=Python]
def solucion(opt, monedas, s, i, j):
if i > j:
    return s

if i == j + 1:
    s.append(i if monedas[i] > monedas[j] else j)
    return s

opt_i = opt[i + 2][j] if monedas[i + 1] > monedas[j] else opt[i + 1][j - 1]
opt_j = opt[i + 1][j - 1] if monedas[i] > monedas[j - 1] else opt[i][j - 2]

if monedas[i] + opt_i > monedas[j] + opt_j:
    s.append(i)
    
    if monedas[i + 1] > monedas[j]:
        return solucion(opt, monedas, s, i + 2, j)
    else:    
        return solucion(opt, monedas, s, i + 1, j - 1)
else:
    s.append(j)
    
    if monedas[i] > monedas[j - 1]:
        return solucion(opt, monedas, s, i + 1, j - 1)
    else:
        return solucion(opt, monedas, s, i, j - 2)
\end{lstlisting}

Siguendo estos pasos recursivamente obtenemos la secuencia de monedas que Sophia deberia elegir para obtener la ganancia maxima.
